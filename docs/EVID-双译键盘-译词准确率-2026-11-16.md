# EVID · 双译键盘 译词准确率实测（离线，2026-11-16）

> 用途：上架前「译词准确率」P0 的实测数（离线可跑、不依赖真机）。口径按评审官 2026-11-16 要求。

## 一、口径（评审官 5 条）
1. **抽样**：英→中 122 词、中→英 118 词，取自**常用高频词**，逐词清单见仓库 `tools/eval_gold_en2zh.tsv`、`tools/eval_gold_zh2en.tsv`（开源可复现，非临时挑词）；期望值含合理近义（如 thanks=谢谢|感谢）。
2. **数据源**：用**随包同版** `Keyboard/en2zh.txt`、`Keyboard/zh2en.txt`（即将要打进 B2.4 包的那两份；commit 见仓库）。
3. **判对规则**（`tools/eval_glossary.py`，可复跑）：
   - 归一化（去空格标点、小写）后，译词命中「期望列表任一」即判对（含近义）；
   - **首选**：该词最常见义；**前3**：英→中按 ECDICT 该词前 3 个义项是否含正确义；
   - 中→英「前3」离线无候选列表，标注 N/A（需真机引擎出候选另测）。
4. **目标**：首选 ≥95%、前3 ≥95%，分方向报。
5. 附错例清单。

## 二、结果
| 方向 | 首选 | 前3 |
|---|---|---|
| 英→中（输入英文查中文） | **122/122 = 100.0%** | **119/122 = 97.5%** |
| 中→英（输入中文查英文） | **115/118 = 97.5%** | N/A（离线无候选，真机测） |

两项首选与前3均 **≥95%，达标**。

## 三、错例清单（全部）
- 英→中 首选：无。
- 英→中 前3（ECDICT 义项边界，非首选错）：open（前3=公开|户外|空旷，未含"打开"）、sad（忧愁|悲哀，未含"悲伤/难过"）、orange（柑橘|桔子|橘色，未含"橙"）。仅影响"前3"这一宽松口径，首选全对。
- 中→英 首选：拿→to hold（"take"亦对，近义）、是→to be（"to be"实为 是 的主义，黄金集期望"yes"偏窄）、请→to ask（"please"亦对，近义）。3 条属近义/期望偏窄，非硬错。

## 四、说明（重要·版本差异，别误读）
- 本次 97.5% 的**中→英**对应**新生成 zh2en 表**（已修 CC-CEDICT「取首条→surname/abbr/variant/多音字错义」问题，如 水→surname Shui、读→comma、给→to 已修正）。
- **此前已发用户的 `KBSpike-B2.3-mem.ipa` 里仍是旧 zh2en 表，其“中→英”实测仅 70.3%**（surname/variant 等错义）。**所以译词准的一版要装随后的 B2.4 包**（引擎/UI 与 B2.3 相同，只是中→英词表更正）。
- 英→中同版无差异（ECDICT 未变，仅 +sad/orange 两条纠正）。

## 五、复现命令


## 六、局限
- 中→英「前3」需真机引擎出候选列表，离线未测；gold 为常用词集（非随机全量），生僻词可能取次义。≥95% 结论限于常用词层。
