## 生成方式
- 解析官方 TSV（跳注释头、`词 \t [词性.]释义...`），去词性前缀，单键多义合并 **≤3**，去重。
- **只补缺口、不改写已有干净词条**（保证 `eval_gold` 不降）：新词条仅当 key 不在现有 `Keyboard/zh2en.txt|en2zh.txt` 时加入；已有关键词保持原值。
- 输出：`键<TAB>译文`、无 BOM、无表头、单 Tab、LF、按 key 升序。
