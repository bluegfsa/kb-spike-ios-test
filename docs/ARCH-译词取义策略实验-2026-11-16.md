# ARCH · 译词取义策略实验与结论（2026-11-16）

> 背景：评审官/产品要求「系统性修取义（常用义优先、过滤专名/疾病/古义），别逐条 OVERRIDES」。
> 我先做最小原型验证再拍板（不靠想象）。同一套 122 词常用词黄金集（`tools/eval_gold_en2zh.tsv`）实测 4 种取义策略：

| 策略 | 说明 | 英→中首选准确率 |
|---|---|---|
| S0 首义 | ECDICT 首个词性行首义（现行） | 93.4% |
| S1 词频max | 该词全部义项中 rime 词频最高者 | **77.9%（更差）** |
| S2 首义常用保留 | 首义权重≥20000 才保留，否则取 max | 82.0%（更差） |
| S3 低权重才切换 | 首义 rime 权重<2000 才改用 max | 95.1%（对黄金集，但见下） |

## 结论（重要）
1. **按 rime 词频挑「最常用中文义」并不等于「该英文词的主义」**：义项之间是不同词性/语义，词频只反映中文词本身常用，不反映它是不是这个英文词的主译。故 S1/S2 明显更差（77.9%/82%）。
2. S3 在本黄金集 95.1%，但**换留出样本仍失灵**：典型 `natural→白痴`（“白痴”权重 3281 属常见词、却是自然 的冷僻义）、`super→跑龙套角色`、`performance→施行`——**权重阈值抓不住「常见但非主译」的义项**。
3. 因此「纯自动＋开源数据」无法稳定 ≥95%；逐条 OVERRIDES 又能被留出种子证伪（A 批 100%、留出 95.8%）。

## 建议（需拍板）
可靠且「系统性」的办法是**做一份「常用词人工校正核心词表」**（curated core glossary）：
- 覆盖高频常用词（建议按词频前 N，如 N=1000/2000，正好覆盖验收抽样分层）；每词给**主义**中文，人工/模型生成后人工复核；长尾词仍用 ECDICT 首义。
- 这是「按词频覆盖一个明确词表」的系统工程，不是对测试样本逐条补漏，可稳定复现、可复核。
- 代价：需一次性人力校正 N 词；N 越大越稳、越费时。

在核心词表落地前，当前最佳是 ECDICT 首义＋已知错词校正（B2.6-gloss3，已补 16 条）；但**它过不了「留出样本稳过≥95%」**，不宜判过。

## 追加实验（2026-11-16 续）
又试两招，均不达标（同一 122 词参考集）：
- **CC-CEDICT 反查校验核心**（只收「能反查回该英文词」的义，否则留空）：核心前 2000 留空 12.7%，非空准确率仅 **86.5%**（更差——反查可误配）。
- **混合**（首义被 CC-CEDICT 认可则留，否则取可反查义）：**92.6%**。
- 生成器原型：[tools/gen_core_glossary.py](tools/gen_core_glossary.py)、[tools/gen_en2zh.py](tools/gen_en2zh.py)（`tools/core1000.tsv`/`core2000.tsv` 为实验产物）。

结论不变并加强：**纯自动/规则取义无法稳定 ≥95%**（首义 93.4 / 词频max 77.9 / 首义常用保留 82 / 混合 92.6 / 反查核心 86.5）。

## 执行评估（范围/排期，需知悉）
要「2000 核心词稳过 ≥95%」，只能按董事长定的「**模型出主义＋人工复核**」**逐词权威定主义**（内容工程，非算法）。这是 2000 词的逐词产出＋复核，需分批（建议 500/批，每批评审官抽 ≥30 词核），**不是一次能出**；每批都要重打包＋测试双 seed 回归。若排期紧，需在「先缩到 1000 高频层验收 / 或接受更高留空率」之间取舍——请董事长/PM 明确优先级与可接受批次节奏。
