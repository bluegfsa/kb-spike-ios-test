# ARCH · 双译键盘 #5 多字词翻译 / #6 英文连续输入 修复设计（2026-11-18）

> 来源：用户真机 6 条缺陷中的 #5、#6（董事长派架构师）。范围仅译词/输入逻辑，不涉 UI。

## #5 三字及以上不显示翻译

**根因**：`Cedict.lookup` 是「前缀查」，候选「你好吗」在 `zh2en.txt` 无该前缀键→空；只有单/双字词命中。

**改法**（`KeyboardModel.translate` + `Cedict.exact` + 新 `PhraseGlossary.swift`）：
1. 先查**高频短语表** `PhraseGlossary.zhToEn`（你好吗→How are you、不知道→I don't know、多少钱→How much…常用短语必须能出）。
2. 再**整词精确查** `Cedict.exact`（键完全相等，避免前缀误取）。
3. 仍无则**贪心最长匹配分词**：把词切成若干已知词各取英译、空格拼接（宁缺毋滥，无译字跳过）。
- `recomputeTranslations` 改用 `translate`，候选旁显译文对多字词也生效。

## #6 英文态空格即确认、无法连打/连续翻译

**根因**：英文态 `space()` 走 `clearComposition()` 清空 buffer 且译文只算当前词、空格即消失；观感像「一按空格就收尾」。

**改法**（`KeyboardModel.space` / `input` / `backspace` / 新增 `enSentence`）：
- 英文态**空格＝插入一个空格并继续**，不清空已得译文：把当前词译文并入 `enSentence`（已提交词译文队列），`primaryTranslation = enSentence 拼接`。
- 打字时当前可见译文＝`enSentence`＋当前正在打的这个词的译文（**逐词实时刷新、连续累积**）。
- `backspace` 同步重算；`clearComposition`（切模式/换行）清空 `enSentence`。
